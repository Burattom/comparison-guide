## タイトル
光回線の乗り換えで失敗しないために、確認すべき3つのこと

## 本文

光回線を乗り換えるとき、多くの人が「月額料金が安いかどうか」だけで判断してしまいます。
しかし実際に満足度を左右するのは、もっと別のポイントです。

### 確認すべき3つのこと

**① 工事費の実質負担**
「工事費実質無料」と書かれていても、分割払いが残り、途中で解約すると残額が請求される場合があります。

**② キャッシュバックの受取時期と条件**
「最大◯万円」という表現には条件があることが多いです。受け取りまでに手続きが必要で、期限を過ぎると無効になるケースもあります。

**③ 契約期間と更新月**
更新月を外して解約すると違約金が発生します。現在の回線の更新月を先に確認し、新しい回線の開通日を調整するのが安心です。

### 回線種別という見落としがちなポイント

光回線は大きく2つに分かれます。

- **独自回線**（NURO光・auひかり・eo光・コミュファ光）：自社の光ファイバー。速く、夜間の低下が少ない。ただしエリア限定
- **光コラボ**（ドコモ光・SoftBank光・GMO光アクセスなど）：NTTのフレッツ網を共有。全国対応で工事なしの乗り換えがしやすい

BNRスピードテストの直近60日中央値では、独自回線は夜間低下が「NURO光 なし／auひかり -5%」なのに対し、光コラボは「ドコモ光 -42%／SoftBank -24%」という差が出ています。

### 実測速度の目安

| 回線 | 下り | 上り | Ping |
|---|---|---|---|
| NURO光 | 976 Mbps | 782 Mbps | 11.5 ms |
| auひかり | 706 Mbps | 622 Mbps | 16.3 ms |
| ドコモ光 | 629 Mbps | 480 Mbps | 21.0 ms |
| ソフトバンク光 | 580 Mbps | 471 Mbps | 17.1 ms |
| フレッツ光ネクスト | 407 Mbps | 300 Mbps | 23.9 ms |

※ みんなのネット回線速度・直近3か月平均。環境により変動します。

### 用途別の選び方

- 4K動画や大容量ダウンロード → NURO光
- オンラインゲームの低ラグ → NURO光／auひかり
- テレワーク・アップロード → 上りが速いNURO光／auひかり
- スマホのセット割・全国対応 → ドコモ光／SoftBank光
- 工事なしで乗り換え → GMO光アクセスの転用・事業者変更

### まとめ

光回線は「どこが一番安いか」だけでは決まりません。
**回線種別 → 工事費 → 特典の受取条件 → 契約期間** の順で確認すると、失敗が減ります。
